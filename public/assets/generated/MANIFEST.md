## Governance

- Treat these as source-controlled design assets, not disposable screenshots.
- Do not silently replace an asset. A replacement should be a deliberate design change with a new commit and updated provenance.
- Visual-regression runs should continue to use `references/world-agent-reference.png` as the golden design frame and these assets as implementation building blocks.
