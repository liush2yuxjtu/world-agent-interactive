01

Design Principles

Model before decoration

世界模型是视觉主角，产品 chrome 保持安静。

Causality is visible

用户能看到指标为何变化、证据来自哪里、动作影响什么。

Uncertainty is explicit

Observed / Inferred / Simulated 绝不混为一谈。

Human control stays obvious

Agent 提案可审查，外部写操作必须显式批准。
